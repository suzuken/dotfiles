# deck：意思決定のための資料

経営や関係者に何かを決めてもらう資料を作る。理解のための資料は `explainer` を使う。

1. `decision-deck-architecture` で、背骨の問いと決定項目を、本文を書く前に固める
2. 社内の一次情報は `source-fact-intake` で確定度を付けて取り込む
3. 主張の前提を `fan-out-research` で反証にかける
4. `exec-deck` で HTML にする。組織のブランドで作るなら、その組織のブランド skill を重ねる
5. 配布前に `multi-persona-review` で、読み手の立場から穴を探す
6. 当日の進行が要るなら `meeting-run-design` を使う

**返答**：決めてもらうこと、資料の構成、反証やレビューで変わった点。
